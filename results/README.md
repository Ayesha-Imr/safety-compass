# Safety Compass Result Artifacts

This directory contains the lightweight Phase 3 and Phase 4 result artifacts needed for documentation, packaging, and follow-up analysis.

Included:

- Phase 3 drift logs, summaries, plots, baselines, and combined analysis.
- Phase 4 drift logs, behavior summaries, raw generations, behavior score CSVs, plots, baselines, and combined drift-vs-behavior analysis.
- Kaggle logs for completed experiment runs.

Not included:

- Phase 4 LoRA adapter directories and model weight files. The three adapter weights are large local artifacts and are intentionally excluded from git. They can be regenerated by rerunning the Phase 4 Kaggle kernels or shared through a model/artifact store if needed.

Primary files for Phase 5:

- `phase3/analysis/phase3_analysis.json`
- `phase3/analysis/comparative_cosine_drift.png`
- `phase4/analysis/phase4_behavior_analysis.json`
- `phase4/analysis/drift_vs_behavior_table.csv`
- `phase4/analysis/drift_vs_behavior_plot.png`
